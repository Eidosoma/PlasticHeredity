# Codex Chapter 5 Phi-r extension preregistration

## Purpose

This additive program asks whether any prospectively specified information-
dynamic description is reproducibly associated with, localized around, or
causally coupled to the already established plastic-heredity control effect.
It preserves the registered negative public nine-atom result and the complete
R0 result. No estimator may overwrite either result.

The program is bounded to 24-matrix scientific cohorts and 80 CPU-hours. No
48-matrix campaign is authorized. Every substantial run is detached,
checkpointed by catalytic matrix, candidate-separated, and replayed exactly.

## Fixed phases

1. **PX1 — fresh confirmation.** Test R0's generational full-block result and
   a prospective catalytic-flux representation on 24 fresh matrices, both
   candidates, two replicates, and four continuously controlled arms.
2. **PX2 — identical broken-state recovery.** Restore the same naturally
   broken daughter across renewal-directed arms and measure explicit branch
   transition pairs without joining unrelated branches.
3. **PX3 — direct Phi control.** Develop a candidate-separated ridge surrogate
   on development-only matrices, freeze it, and test exhaustive Phi-directed
   substitutions on 24 fresh confirmation matrices.
4. **PX4 — simulator moderator.** Factor the material Codex/Fable contract
   differences with neutral shared inputs and the physical outgoing rule.
5. **PX5 — generative null remeasurement.** Replay the sealed natural,
   homogeneous, coupling-deranged, and fission-only campaign with the new
   information instruments.
6. **PX6 — redundancy robustness.** Apply a fixed correction continuum and
   analytic envelope without selecting a favorable definition.

All phases run even when an earlier phase fails. A failed gate remains at full
prominence and limits later interpretation. Independent phases cannot rescue
or replace a failed phase.

## Shared estimators

### Material representation

Add 0.5 to all molecular counts, take all 100 centered-log-ratio coordinates,
apply an average-rank Gaussian copula transform, and split active coordinates
with the arm-independent Fiedler partition of the symmetrized log-beta graph.

The full-block statistic is:

`I(X;X') - I(A;A') - I(B;B') + min(AA, AB, BA, BB)`.

Sequential trajectories are transformed once as unique observations before
adjacent pairing, exactly matching R0. Branched experiments supply explicit
past/future pairs and never create transitions across branch boundaries.

### Functional catalytic-flux representation

For every composition, use the frozen Codex kinetics:

- `b = 1 + beta@n/N`
- `J_i = k_join*rho_i*N*b_i`
- `L_i = k_leave*n_i*b_i`

Sum joining and leaving flux within each fixed beta module, yielding four
coordinates: module-A join/leave and module-B join/leave. Apply `log1p`, the
same rank transform, and the same full-block statistic with modules as parts.

The public two-macro PhiID atom vector is always retained as a secondary
reading. Atom direction is past/source to future/target.

## Inference and integrity

- Catalytic matrix is the inference unit.
- Candidates and registered replicate/branch-half cells are never pooled.
- Major tests use 4,096 whole-matrix bootstrap draws and 4,096 paired
  whole-matrix sign randomizations.
- Holm correction is applied across each complete registered primary family.
- Equivalence uses a 90% interval wholly inside the sealed margin.
- Random edit selection and future simulation use separate seed domains.
- Arm and simulator-variant identity are absent from paired future seed keys.
- Extinction is retained; matrices are never replaced after sealing.
- Every phase requires exact second replay and output readback.
- Scientific output is written only after validation, registration, and smoke
  checks pass.

## Advancement and resource rules

The allocation is PX0 2, PX1 8, PX2 10, PX3 development 20, PX3 confirmation
12, PX4 14, PX5 12, and PX6 2 CPU-hours. A phase pauses at a valid checkpoint
instead of silently changing matrices, branches, endpoints, or inference
draws. At most 12 workers and one scientific phase may run at once.

## Claim boundaries

A positive result can establish only a representation-, scale-, and simulator-
specific information-dynamic relationship with plastic heredity. Direct Phi
control requires a prospective development gate and a completely fresh
confirmation gate. No result supports consciousness, agency, life, biological
memory, Phi as a cause, a universal origin-of-life mechanism, or metaphysical
claims. Cross-clean-room agreement is claimed only for exactly matched tests.
