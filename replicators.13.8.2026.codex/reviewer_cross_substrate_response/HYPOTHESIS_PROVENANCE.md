# Hypothesis provenance and source firewall

## Permitted carry-over

Before this package was created, the investigators knew of an unpublished,
positive exploratory exercise suggesting that a cellular automaton might show
plastic-heredity break-and-renewal.  That fact motivates the hypothesis tested
here and has **zero evidential weight** in this campaign.

## Prohibited inputs

No file below `../NewIdeas/`, and no code, rule, parameter, metric, seed,
selected example, effect size, numerical result, plot, or implementation detail
from that exercise may be opened, imported, copied, hashed, or used to make a
scientific choice in this package.

The implementation may use only:

1. the published Kamimura--Kaneko spatial hypercycle description;
2. the published Sayama Evoloop specification and public Golly transition
   table as a rule reference;
3. the already public break-then-renewal topology documented in this
   repository; and
4. new code, parameter screens, states, and seed domains created below this
   directory.

## Correct description

This is a prospective, source-isolated test of an externally generated,
outcome-aware hypothesis.  Its developmental pilot is explicitly
non-evidential; only a separately authorized prospective confirmation could
carry confirmation status.  It is not an outcome-blind discovery and the
unpublished exercise supplies no evidence.
