# Reviewer question and analysis plan

## Question

Can the narrow plastic-heredity process--an inheritance break followed later
by a renewed short inherited run--occur in a substrate other than GARD?

## Answering strategy

Two deliberately different CA contracts are tested.  The spatial hypercycle
has stochastic local chemistry and endogenous cluster division.  Evoloop has
a deterministic local rule, explicit self-reproducing structures, and
stochastic ecological encounters.  Each retains its own calibrated
parent--offspring threshold while sharing the same event topology, null,
statewise branch split, and inferential gates.

The developmental pilot is fully disclosed and cannot count as confirmation.
It exists only to determine whether each model can supply enough unambiguous
lineages and events for the fixed confirmation design.  No favorable model,
threshold, parameter cell, endpoint, or analysis is selected after the pilot.

## Interpretation

- If one model passes, the operational process transfers to at least one
  tested CA substrate.
- If both pass, it transfers to two contrasting tested CA substrates.
- If neither passes, transfer is not supported under these contracts.
- A failed or ineligible model remains visible and is never pooled away.

The complete frozen numerical contract is in `PREREGISTRATION.md` and the
machine-readable protocol emitted by `prepare`.
