# Reviewer comment addressed by this package

This package addresses items 2--4 of the supplied lineage-identity challenge.
The text below is retained as the design input; it is not treated as a result.

## 2. Sibling-versus-stranger baseline

Compute within-lineage similarity and cross-lineage similarity using 20
lineages with different seeds under the same catalytic rule. Heredity requires
within-lineage similarity to be substantially greater than cross-lineage
similarity. The requested literal failure condition is overlap of the two
distributions.

## 3. Post-break fork

Clone a post-break form and run two independent stochastic futures. Test
whether the sibling forks remain mutually above `H=0.90` for eight generations
while a fork from a different lineage remains distinguishable.

## 4. Attractor census

For 50 capable catalytic rules, count the distinct stable textures reached
from many random starts. The requested literal criterion requires at least two
co-existing stable forms per rule.

## Scope correction retained in the protocol

Ordinary F12 certifies adjacent parent-to-selected-daughter renewal and usually
does not define one coherent form. The strict coherent-eight event is therefore
the primary source of a testable form `B`; F12 is a descriptive, non-rescuing
control. The literal reviewer readouts are reported alongside statistically
defined primary gates rather than replacing them.
