# Hypothesis boundary

This is an exploratory, reviewer-motivated clean-room stress test. The Wagner
GRN documents and completed result summaries supplied only the hypothesis that
an inherited lineage register might stabilize or select a form. They are
classified as `hypothesis_only_non_evidentiary` and are never pooled with the
GARD outcomes.

No Wagner source code, tests, scripts, notebooks, or configuration modules are
read, imported, copied, or executed. The carrier mechanism in this directory is
new code written against the frozen reconstructed GARD simulator and its
verified data products.

The outcome is not evidence for the current preprint, not a replication of the
Wagner experiments, and not an independent replication of GARD plastic
heredity. It is an outcome-informed follow-up used to generate and stress-test
hypotheses for later work.
