# Reporting boundary

This campaign is an exploratory, outcome-informed follow-up in the frozen
reconstructed GARD simulator.  It is not evidence for the current preprint and
is not an independent replication of GARD, Wagner GRNs, biological memory, or
prebiotic chemistry.

NewIdeas GRN documents and completed data summaries supplied only the carrier
and boundary-of-order hypotheses.  No Wagner source code, test, notebook, or
configuration is read, imported, copied, or executed here.  No NewIdeas result
is pooled with a GARD outcome.

Use “boundary of order” by default.  Use “edge of chaos” only if the registered
stochastic damage-spreading and deterministic stability gates both pass in
both simulator candidates.  Report F12 and strict eight separately, and state
that the frozen-carrier overlay cannot rescue the earlier carrier result.
