# Strict-eight matched-donor and switch-lock campaign

This fresh clean-room campaign follows up two exploratory observations without
adding them to the current preprint's evidence. It asks whether an F12 event
that subsequently completes the registered strict-eight geometry carries more
lineage information than an identically aged matched F12-only event, and
whether a temporal switch-then-lock intervention can stabilize the selected
form after external support is removed.

Every donor B is captured at the third daughter of its qualifying post-break
run: the first registered strict window or the first F12 recovery. A strict
donor therefore never receives the eighth-daughter head start used in the
earlier descriptive study. Global event time is included in matching. Fresh
stochastic forks are disjoint from the selection trajectory.

The static cosine test remains primary. A four-generation, target-specific
reservoir wave and a phase-aligned orbit score are explicitly engineered and
secondary. They cannot rescue a failed static heredity gate.

Long work is checkpointed per candidate/matrix and replay verification writes
one resumable receipt per checkpoint. Run from `replicators.13.8.2026.codex`:

```bash
./reviewer_lineage_identity_response/followup_strict8_switch_lock_cleanroom/run_detached_pipeline.sh 16
```

Status is in `artifacts/STATUS.json`. The cumulative soft and hard limits are
7.5 and 8 hours.
