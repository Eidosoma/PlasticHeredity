# Reporting boundary

- This is exploratory next-preprint work, not evidence for the current
  preprint and not a replicated test of a claim made there.
- F12 is the weaker operational break-and-three endpoint. Strict eight is a
  rarer, stronger outcome-conditioned subset. They are never pooled.
- The two simulator candidates are alternative reconstructions and are never
  pooled to create a pass.
- Selecting B states that later persist asks whether strict-eight is an
  enriched phenotype; it does not estimate its unconditioned prevalence.
- The target-specific wave is an engineered external cue. Persistence only
  while that cue is present is external maintenance, not autonomous heredity.
- Phase-aligned similarity is secondary and cannot rescue the reviewer's
  static lineage-identity test.
- Earlier carrier, dynamic-regime, and plasticity-persistence outcomes are
  hypothesis generation only and are not pooled with this fresh cohort.
- No Wagner implementation, test, notebook, configuration, or code is read,
  imported, copied, or executed.
- A verdict requires every generated checkpoint to replay exactly. Outputs
  produced before that audit are provisional.
