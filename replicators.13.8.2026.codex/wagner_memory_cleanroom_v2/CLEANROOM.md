# Clean-room boundary

This is a new implementation of the Wagner memory experiments. It does not
import, execute, copy, inspect, or translate any NewIdeas source code, tests,
scripts, notebooks, or executable configuration. V1 is preserved as an audit
artifact and is not imported.

The contract was reconstructed from prose plus retained report, registration,
analysis, and rulebook data. Those inputs establish observable scientific
semantics; all algorithms below were independently specified. Runtime source
scanning rejects NewIdeas and v1 dependencies.

Every run seals its complete Python source, protocol, dependency lock, accepted
rulebooks, proposal log, runtime environment, aggregate cell records, per-cell
future digests, and independently regenerated future-ID replay sample.
